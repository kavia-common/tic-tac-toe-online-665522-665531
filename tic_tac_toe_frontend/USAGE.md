# Tic Tac Toe — Violet Dreams

- New Game resets the board and starts with X.
- Mode toggles between PvP and AI. Changing mode resets the game.
- Undo reverts the last move (works in both modes).
- AI follows a simple strategy: win if possible, block, then center/corner/side.
- Keyboard: Tab through cells (buttons) and press Enter/Space to play.
- Status region is announced via aria-live for changes (turns, winner, draw).
